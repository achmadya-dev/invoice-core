# Start here

1. Follow the [README](README.md) to run Invoice Core locally. It does not require an account, credentials, or a database.
2. Read the [product scope](docs/PRODUCT.md) and [invoice rules](docs/DOMAIN.md) before extending a workflow or calculation.
3. Use the [architecture](docs/ARCHITECTURE.md), [design](docs/DESIGN.md), [code standards](docs/CODE_STANDARDS.md), and [invoice patterns](docs/PATTERNS.md) to find the right boundary for the change.
4. Track work through the [issue and pull request workflow](docs/WORKFLOW.md). Run [verification](docs/VALIDATION.md) before asking for review.

Read [AGENTS.md](AGENTS.md) when working with a coding agent. Keep planning experiments under ignored `prototypes/`; follow the [prototyping guide](docs/PROTOTYPING.md) for screenshots and scope.
