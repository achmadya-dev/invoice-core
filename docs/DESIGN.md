# Invoice Core design

**Dispatch Desk** is an operational workspace centered on a single invoice sheet. Edit the document in place or switch to a clean read-only preview. Both modes share the same draft and document model.

## Visual system

- Deep indigo (`#282049`) frames navigation and the proof. Working actions use indigo (`#4837a6`), the desk uses lavender (`#e8e5f4`), and yellow (`#f9e080`) marks the brand and amount due. Dark theme (following `data-theme="system"` from SSR through hydration or toggled from the topbar **Dark mode** switch) adjusts the desk, modals, error/404 shells, and workspace while preserving the white print proof.
- Bricolage Grotesque gives headings and the wordmark their shape; system sans keeps form labels and inputs familiar; tabular and monospace figures distinguish amounts and record references.
- The amount slip is the strongest mark inside the invoice. Editing controls never appear in the read-only or printed document. PDF uses the same document data and calculation as preview, with a paginated A4 layout and bundled regular/bold Noto Sans fonts for ASCII and non-ASCII text.
- Present **Invoices**, **Products**, and **Companies** as three Base UI tabs with full keyboard navigation (`ArrowLeft`/`ArrowRight`/`Home`/`End`) on a single page, keeping the same searchable and paginated list layout across Invoices and Products and searchable list layout on Companies.
- Invoices opens on the paginated history with **Backup** and **Create invoice** in the header. Clicking **Create invoice**, **Duplicate**, or a saved row opens the invoice sheet in a wide modal with **Edit / Preview**, **Accent color** (showing the active hex value, an optional reset-to-default control, and automatic >= 4.5:1 WCAG contrast adjustment on white paper), and **Layout** controls in the modal header, a light options strip above the framed white sheet, and primary actions below it. Download PDF is available in both Edit and Preview modes. The white sheet uses a small gutter and a shadow for separation.
- Keep Company, Currency, country, discount-type, tax-label, Accent color, and Layout controls in the separate options area and modal header above the sheet, placing compact **Use saved client** and **Add product** modal-trigger buttons beside **Bill to** and **Line items**. Upload or replace the logo in the sheet header. Show entered values and examples as editable document text on the paper, without persistent input borders. Show computed line amounts in the editable table, allow moving line items up or down when multiple items exist, display the currency code beside both fixed discount and shipping inputs, and give each item description a full row on narrow screens. Place Notes and Terms side by side above full-width Payment details, stacking at narrow widths. Use labeled Base UI controls, keep dropdown triggers stable, and surface storage errors inside active dialogs. Manage products, companies, and backups in dialogs.
- The brand mark is original. [Bricolage Grotesque](../public/licenses/OFL-Bricolage-Grotesque.txt) and [Noto Sans](../public/licenses/OFL-Noto-Sans.txt) ship under the SIL Open Font License.

## Usage

Use visible labels or document headings and examples, descriptive accessible field names, an obvious keyboard focus indicator, and explicit feedback for invalid values and storage failures. Require a confirmation when replacing stored data. Blank fields show examples that are never stored or exported.
