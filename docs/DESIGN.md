# Invoice Core design

**Ledger & Proof** is an editorial financial workbench centered on a calm ledger workspace and a single crisp invoice proof sheet. Edit the document directly in place or switch to a clean read-only preview. Both modes share the same draft and document model.

## Visual system

- Light mode uses Warm Alabaster (`#f6f5f2`), white paper surfaces (`#ffffff`), hairline borders (`#e2dfd7`), Carbon Ink (`#18181b`), and Deep Spruce (`#165947`) for interactive emphasis and the default document accent. Dark mode uses Warm Obsidian (`#111110`), graphite surfaces (`#181816`), and high-contrast Soft Spruce (`#6ee7b7`) while keeping the `.ic-proof` paper sheet pinned to crisp white (`#ffffff`) and carbon ink for accurate WYSIWYG editing and printing. A subtle gold stamp (`#f4d06f`) is reserved strictly for the geometric brand mark.
- `Bricolage Grotesque` anchors the wordmark and compact headings; system sans keeps form labels and inputs legible; tabular monospace figures distinguish amounts, dates, and invoice numbers.
- Uniform `1px` perimeter hairlines and flat tonal hierarchy replace decorative bentos, icon squircles, and thick curved left/top accent bars across cards, dialogs, and invoices. In the `Modern` invoice layout (synced across HTML preview and PDF), crisp horizontal structural rules frame the header and table while the **Amount due** band renders in high-contrast solid accent fill with white ink (`>= 4.5:1` WCAG AA contrast).
- PDF uses the same document data and calculation as preview, with a paginated A4 layout and bundled regular/bold Noto Sans fonts for ASCII and non-ASCII text.
- Present **Invoices**, **Products**, and **Companies** as three underline-style Base UI tabs with full keyboard navigation (`ArrowLeft`/`ArrowRight`/`Home`/`End`) on a single page, using an aligned ledger list for **Invoices** (right-aligned tabular amounts and single-primary CTA discipline per tab) and consistent searchable lists for **Products** (paginated at 10 per page) and **Companies**.
- A seamless topbar (`Invoice Core`, **Backup**, and the minimalist **Dark mode** switch) stays compact across desktop and narrow mobile viewports. **Create invoice** sits in the workspace header (primary on **Invoices**, secondary when viewing **Products** or **Companies** so **Add product** / **Add company** remains the single primary CTA).
- Clicking **Create invoice**, **Duplicate**, or a saved row opens the invoice sheet in a wide, minimally nested modal with **Edit / Preview**, **Accent color** (default `#165947`, active hex readout, reset control, and automatic `>= 4.5:1` WCAG contrast adjustment on white paper), and **Layout** controls in the modal header, a flat edge-to-edge options strip above the framed white sheet, and grounded primary/secondary actions in a dedicated modal footer bar. Download PDF is available in both Edit and Preview modes.
- Keep Company, Currency, country, discount-type, tax-label, Accent color, and Layout controls in the options bar and modal header above the sheet, placing compact **Use saved client** and **Add product** modal-trigger buttons beside **Bill to** and **Line items**. Upload or replace the logo in the sheet header. Show entered values and examples as editable document text on the paper without persistent input borders, allow moving line items up or down when multiple items exist, display the currency code beside both fixed discount and shipping inputs, place Notes and Terms side by side above full-width Payment details, use accessible Base UI controls, keep **Backup** organized as a flat summary strip + action rows + uniform-border reset zone, and surface storage errors inside active dialogs.
- The brand mark is original. [Bricolage Grotesque](../public/licenses/OFL-Bricolage-Grotesque.txt) and [Noto Sans](../public/licenses/OFL-Noto-Sans.txt) ship under the SIL Open Font License.

## Usage

Use visible labels or document headings and examples, descriptive accessible field names, an obvious keyboard focus indicator, and explicit feedback for invalid values and storage failures. Require a confirmation when replacing or clearing stored data. Blank fields show examples that are never stored or exported.
